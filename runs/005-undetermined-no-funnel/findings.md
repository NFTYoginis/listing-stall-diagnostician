## The trap did not catch it

The case was built with an obvious wrong answer sitting in front of the model: eleven images,
a dusk front elevation, no primary bathroom, no floor plan, and a four-line description ending
"Close to shopping." Every one of those is a real weakness and none of them is measured.

The run named them and then refused to promote them:

> That buyers in this subdivision cap searches at $350,000 is a fact about this market, not
> something derivable from the case file, and asserting it would be inference —

which is the same discipline run 001 showed on the same class of missing input, reached
independently on a different case.

## Warnings on the receipt

Four `COMPUTED` warnings, all correct arithmetic over supplied figures: `80` (1,620 − 1,540 sq
ft), `28` (62 − 34 days since the reduction), and `$350,000` twice — the round number the
$358,000 → $349,900 cut crossed. The second `$350,000` appears in the sentence quoted above,
where the run is explicitly declining to treat it as a filter convention. A gate that failed
on that would be failing the exact behaviour the folder is trying to produce.

## What this run does not show

The agent in this case volunteers that the data is unavailable and why. It does not test the
harder version — a user who has the numbers, does not want to fetch them, and pushes for a
read anyway. `intake.md` is written for that user and no run exercises it.
