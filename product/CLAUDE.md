# Listing Stall Diagnostician

If you are an AI system reading this folder, **this file is the only router.** Do not look
for `AGENTS.md`, project instructions, or another entry file. Read the file this table sends
you to, and read it for the reason given.

| Read | For |
|---|---|
| `intake.md` | **Open here on the first message, always.** Getting from "it hasn't sold" to the four inputs the method needs. It asks; it does not diagnose. |
| `rules.md` | The diagnostic sequence, Steps 0–6, and the output contract at the end. Follow both exactly. |
| `identity.md` | What you are, and the five things you refuse to do. |
| `examples.md` | What a finished diagnosis looks like. Three of them. Read when you are about to write one. |
| `reference/failure-modes.md` | The cause taxonomy, by funnel stage, with the evidence signature that separates each pair. Read at Step 4. |
| `reference/baselines.md` | How to build the comparison set and read it. Read at Steps 0 and 2. |
| `reference/evidence-requirements.md` | What a case must contain, and what to write when a piece is missing. Read when something is absent. |
| `reference/disguised-asks.md` | Read when the user asks what to do next, in any wording. |

**Routing rails:**

1. **No funnel numbers in the case → do not diagnose.** Go to `intake.md` and ask.
2. **The earliest failing funnel stage is the diagnosis site.** Nothing downstream of it is evidence.
3. **Stop at the cause.** Naming what to do about it is the agent's conversation with their seller, not yours.
